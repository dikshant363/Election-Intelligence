# Contributing to Election Intelligence Platform

## Overview
Thank you for your interest in contributing to the Election Intelligence Platform! This document outlines the process for contributing to the project.

## How to Contribute
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Make your changes
4. Write or update tests as needed
5. Ensure all tests pass
6. Commit your changes with a clear message
7. Push to your fork
8. Create a pull request

## Development Setup
See `README.md` for environment setup instructions.

## Code Standards
- Follow the style guide defined in `AGENT_RULES.md`
- Write clear, maintainable code
- Document all public APIs
- Include tests for new features

## Pull Request Process
1. Ensure your code follows the project style
2. Add tests for any new functionality
3. Update documentation as needed
4. Ensure CI passes
5. Address any review feedback

## Reporting Issues
Use the GitHub issue tracker to report bugs or request features. Include:
- A clear description of the issue
- Steps to reproduce
- Expected and actual behavior
- Your environment details
