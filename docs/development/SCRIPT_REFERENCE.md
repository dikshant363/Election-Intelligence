# SCRIPT_REFERENCE.md

## Development Scripts

All scripts are located in `scripts/` and can be executed directly.

### bootstrap
Initial environment setup - installs dependencies and configures tools.

### setup
Development environment configuration - sets up virtual environments and tools.

### format
Code formatting - applies Black, Prettier, and other formatters.

### lint
Code linting - runs Ruff, ESLint, and other linters.

### typecheck
Type checking - runs mypy and other type checkers.

### test
Test suite execution - runs pytest, Jest, and Flutter tests.

### clean
Clean build artifacts and caches.

### doctor
Diagnose development environment - verifies tool installations.

### verify
Run all quality checks - format, lint, typecheck, test.
