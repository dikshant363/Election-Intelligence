# Security Guidelines

## Confidentiality
All source code and election data must be treated as classified information until proper authorization is granted. Access is restricted to authorized personnel only.

## Data Integrity
Election data integrity is ensured through: 
- End-to-end encryption for data transfers
- Tamper-evident logging mechanisms
- Regular security audits

## Compliance
Adheres to: 
- India's Information Technology Act, 2000
- European Data Protection Regulation (GDPR) principles
- Anthropic's Generative AI Principles
