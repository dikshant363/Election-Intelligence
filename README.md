# Election Intelligence Platform\n\nA secure, scalable, politically neutral platform for election intelligence in India, designed for production-grade AI-first software engineering.\n\n## Vision\nTransform election data into verified, citable insights while maintaining strict political neutrality.\n\n## Tech Stack\n- **Backend**: FastAPI, Python, PostgreSQL\n- **Frontend**: Flutter App\n- **AI Engine**: LLM-based analysis with fact-checking\n- **Infrastructure**: Docker (planned), Kubernetes (future)\n\n## Repository Structure\n```\n.\n├── app/              # Backend source code\n├── mobile_app/       # Flutter frontend\n├── db/               # Database schemas & migrations\n├── migrations/       # Schema migrations\n├── scripts/          # Utility scripts\n├── seeds/            # Seed data\n├── prompts/          # AI prompts\n└── docs/             # Documentation\n```\n\n## Documentation Index\n- [README.md](README.md) - Project overview\n- [SETUP.md](SETUP.md) - Development setup\n- [ARCHITECTURE.md](ARCHITECTURE.md) - System architecture\n- [AGENT_RULES.md](AGENT_RULES.md) - Engineering rules\n- [CONTRIBUTING.md](CONTRIBUTING.md) - Contribution guide\n- [TASKS.md](TASKS.md) - Development roadmap\n\n## Quick Links\n- [Issue Tracker](https://github.com/example/election-integrity/issues)\n- [Code of Conduct](CODE_OF_CONDUCT.md)\n- [License](LICENSE)
