## 2026-08-05 - Hardcoded JWT Secret Key and Missing Fallback Error
**Vulnerability:** A hardcoded `JWT_SECRET_KEY` was found inside `app/identity/services/jwt_service.py` (`election-intelligence-secret-key-change-in-prod`). Moreover, the `Settings` class in `app/config/settings.py` was missing the `JWT_SECRET_KEY` variable entirely.
**Learning:** Hardcoded secrets present a major risk because they exist in source control and are often mistakenly deployed in production, leading to total compromise of the authentication system. Moreover, any configuration variables that represent sensitive keys should not have default values assigned so that the application purposefully fails to start if the admin forgets to supply the correct environment variable.
**Prevention:** Always declare sensitive secrets without defaults in configuration classes (e.g., using `pydantic-settings`) and pull them using `os.environ` or `.env` files. Ensure secrets are never hardcoded as strings in the codebase.
